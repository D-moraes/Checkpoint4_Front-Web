# Lista de Tarefas do Programador

Projeto desenvolvido para a disciplina de Front/Web da FIAP.

O projeto consiste em um sistema de gerenciamento de tarefas voltado para programadores, permitindo cadastrar, visualizar, concluir, remover e filtrar tarefas.

## Tecnologias utilizadas

- React
- Vite
- JavaScript
- CSS
- LocalStorage

## Funcionalidades

- Cadastro de tarefas
- Nome, data, descrição e nível de prioridade
- Marcação de tarefas como concluídas
- Remoção de tarefas
- Filtros por status
- Persistência dos dados utilizando LocalStorage
- Interface responsiva

## Estrutura do projeto
O projeto está organizado utilizando componentes React, separando as principais funcionalidades em diferentes arquivos para facilitar a organização e manutenção do código.
